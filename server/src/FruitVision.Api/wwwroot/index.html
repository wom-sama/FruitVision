Nông sản rõ nguồn.
Thông tin cùng một nơi.

Đăng ký hồ sơ, xem nguồn hàng dự kiến và trao đổi với các bên trên nền tảng. Quyền nghiệp vụ được mở sau khi hồ sơ được duyệt.

App FruitVision hỗ trợ gửi ảnh/video qua API để AI trên máy tính nhận diện và đếm quả; tiến độ và hội thoại cập nhật trực tiếp trên app. Trang web này phục vụ kiểm tra tài khoản và API. Giao dịch tồn kho chưa được triển khai.
